## Master Specification

Version: 1.0

# 1. Vision

## Objective

Build an AI-powered learning platform that teaches Python from absolute beginner to intermediate Data Engineer level through one continuously evolving real-world application.

Unlike traditional courses, every lesson contributes to a single production-grade project.

The learner never writes throwaway code.

Every lesson improves the same application.

---

# Core Principles

The platform follows eight non-negotiable principles.

## 1. Learn by Building

Every lesson extends one application.

No isolated toy examples unless introducing new syntax.

Example:

---

## 2. Learn Just Enough

Never introduce concepts before they are needed.

Instead of teaching every possible loop:

Need iteration?

Teach for-loop.

Need indexes?

Teach enumerate().

Need dictionaries?

Introduce dictionaries.

Nothing earlier.

---

## 3. AI is a Mentor

The AI is NOT a lecturer.

The AI behaves like an experienced senior developer.

Responsibilities:

- explain
- guide
- review
- encourage
- examine

Never dump information.

---

# 7. Mission Engine

---

# Purpose

The Mission Engine is the heart of the learning platform.

Its responsibility is to transform a static curriculum into an adaptive learning experience.

Unlike traditional online courses, the Mission Engine never stores complete lessons.

Instead, it stores only structured metadata describing:

- what to teach,
- why it matters,
- prerequisites,
- expected outcome,
- project milestone.

Everything else is generated dynamically by AI.
